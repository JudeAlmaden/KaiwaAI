# Word Database Regeneration

## Problem

The original `words.csv` and `word_forms.csv` files had incorrect mappings where word meanings were mismatched. For example:
- 行く (iku/yuku) - "to go" was showing meanings: "to trip; to get high; to have a drug-induced hallucination"

This was caused by errors during the initial conversion from JMdict JSON files to CSV format.

## Solution

Created `regenerate-word-csvs.mjs` script that:

1. **Reads all JMdict term bank JSON files** (53 files with 524,202 entries)
2. **Extracts word data correctly:**
   - Dictionary form (kanji/kana)
   - Reading (kana)
   - Meanings (from structured content)
   - Part of speech (noun, verb, adjective, etc.)
   - Verb type (godan, ichidan, suru)
   - Adjective type (i-adjective, na-adjective)
   - JLPT level (N5-N1)

3. **Generates verb conjugations:**
   - Regular godan (う-verbs) conjugations
   - Regular ichidan (る-verbs) conjugations
   - Special handling for irregular verbs like:
     - 行く (iku) - て-form is 行って not 行いて
     - する (suru) - fully irregular
     - 来る (kuru) - fully irregular
     - ある (aru) - irregular negative

4. **Generates 40+ conjugation forms per verb:**
   - Polite forms (masu, masen, mashita, etc.)
   - Plain forms (present, past, negative)
   - て-form and progressive
   - Potential, passive, causative
   - Conditional forms
   - Volitional, imperative
   - And many more

## Results

- **words.csv**: 7,146 word entries → `public/database/generated/words.csv`
- **word_forms.csv**: 53,560 conjugated forms → `public/database/generated/word_forms.csv`

## File Organization

```

├── database/
│   ├── source/              # Source data files (do not modify)
│   │   ├── jlpt_levels.csv  # JLPT word list (7,972 entries)
│   │   ├── kanji-import.csv # Kanji database
│   │   └── irregular.csv    # Irregular verb definitions
│   ├── generated/           # Auto-generated by regenerate-word-csvs.mjs
│   │   ├── words.csv        # Dictionary words (7,146 entries)

│   └── new-schema.prisma    # Schema documentation
├── jmdict/                  # JMdict JSON files (53 files, ~524k entries)
├── assets/svg/              # SVG assets
├── icons/                   # PWA icons
└── images/                  # App images
```

## Usage

To regenerate the CSV files:

```bash
npm run regenerate:words
```

This will overwrite:
- `public/database/generated/words.csv`
- `public/database/generated/word_forms.csv`

## Verification

After regeneration, 行く (iku/yuku) now correctly shows:
- **Meaning**: "to go; to move (towards); to head (towards); to leave (for)..."
- **て-form**: 行って (itte) ✓
- **Past form**: 行った (itta) ✓

All verb conjugations are now properly generated with correct handling of irregular forms.

- Readings for conjugated forms are currently simplified (using the kanji form) - could be enhanced to generate proper readings
- The irregular verb list can be expanded in the script if needed
- Future improvements could include:
